sobre

Os projetos abaixo cobrem back-end em Java e Node/TypeScript, um front-end em Laravel/PHP e um app mobile em React Native — todos com autenticação real e pipeline de CI/CD rodando no GitHub Actions, e os de Java com suíte de testes unitários e de integração.

Boa parte deles nasceu de simulações de sistemas do mundo real: um banco digital, uma clínica veterinária, um gerenciador de tarefas — priorizando regras de negócio bem definidas em vez de apenas telas bonitas.
